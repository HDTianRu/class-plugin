# class-plugin

 Yunzai-Bot 课表插件：利用酷学途接口（与鉴权漏洞），绑定教务学号后查询课表、查打卡记录，并通过扫描签到二维码完成签到。

## 安装

1. 将插件放入 Yunzai 的 `plugins/class-plugin` 目录。
2. 复制 `data/cfg_default.json` 为 `data/cfg.json`，填写 `class.token`（教务接口 Token，必填）。
3. 重启 Bot，使插件生效。
4. 后续更新发送 `#更新课表插件`

签到功能依赖 `zxing-wasm`（自带头文件级图像解码，PNG/JPG/GIF/BMP 通用，无需 sharp / canvas 等本地编译依赖），在插件目录执行一次即可：

```bash
pnpm install -P
```

`zxing-wasm` 的 wasm 会从包内本地文件加载，不依赖 CDN，离线环境也能识码。

## 指令一览

| 指令 | 作用 |
| --- | --- |
| `#bind 学号` | 绑定教务学号，绑定后自动返回一张课表验证 |
| `#unbind` | 解除绑定（主人可 `#unbind @某人` 代解绑） |
| `#课表` / `#class` / `#clz` | 查看整周课表 |
| `#课表刷新` | 忽略缓存，重新拉取课表 |
| `#课表 3` / `#课表周三` | 查看指定星期，1~6 为周一~周六，7 为周日 |
| `#今日课表` / `#明日课表` | 查看当天 / 次日的课程 |
| `#签到` | 引用含签到二维码的图片发送，自动识码并签到 |
| `#课表帮助` / `#课表菜单` | 查看帮助图 |
| `#更新课表插件` / `#课表插件更新日志` | 更新插件本体 / 查看更新日志（仅主人） |

说明：

- 指令前加 `#` 与否皆可。
- 主人可用 `#bind 学号 @某人` 为他人代绑。
- 查询他人课表时默认隐藏教师与教室，可用 `class.hideOthersInfo` 关闭。
- 同一用户 5 秒内重复触发只响应一次，避免刷接口。

## 配置（`data/cfg.json`）

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `class.token` | `""` | 教务接口 Token，必填 |
| `class.orgaId` | `"10001"` | 机构 ID |
| `class.checkinTimeout` | `10000` | 打卡接口超时（毫秒），超时退回课表到勤标签 |
| `class.hideOthersInfo` | `true` | 查他人课表时隐藏教师与教室 |
| `class.maxPeriod` | `0` | 最少显示的节数，0 表示自动 |
| `class.scale` | `1.3` | 渲染图片缩放比例 |
| `class.lockTime` | `5000` | 同一用户重复触发间隔（毫秒），0 为不限 |
| `class.checkinBefore` / `checkinAfter` | `60` / `5` | 打卡时间落在上课前后多少分钟内算作该节课 |

## 目录结构

```
apps/      指令入口（课表、帮助、签到、更新）
model/     接口请求与数据整理（class.js 核心逻辑、Cfg/Data 配置与存储）
config/    插件常量与帮助文案
resources/ 渲染模板（课表整周/单天、帮助图）
data/      运行时数据（绑定表、配置、缓存）
```

## 数据与缓存

- 绑定关系保存在 `data/class/data.json`。
- 课表接口结果按学号缓存到当天 0 点，`#课表刷新` 可跳过缓存。
- 打卡接口不缓存，超时或失败时回退到课表接口自带的到勤标签。
